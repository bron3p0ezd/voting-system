# Frontend Voting System

Клиентская часть сервиса анонимных опросов. Стек: React, TypeScript, Vite и Tailwind CSS 4.

## Запуск

Требуется Node.js 22 или новее.

```bash
npm install
Copy-Item .env.example .env.local
npm run dev
```

## Конфигурация окружения

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `VITE_DEV_HOST` | Интерфейс, на котором слушает Vite | `localhost` |
| `VITE_DEV_PORT` | Порт Vite | `5173` |
| `VITE_DEV_ALLOWED_ORIGINS` | Разрешённые CORS-origin через запятую | `http://localhost:5173` |
| `VITE_API_BASE_URL` | Базовый адрес backend API | `http://localhost:8000/api/v1` |

Если список `VITE_DEV_ALLOWED_ORIGINS` пуст, CORS на dev-сервере отключён. Значения с префиксом `VITE_` доступны клиентскому коду, поэтому не храните в них секреты.

## Проверка

```bash
npm run build
```

## Реализованный интерфейс

Административная страница доступна по пути `/admin/polls`. Сначала она показывает форму входа; после успешной авторизации Bearer-токен хранится только в `sessionStorage` текущей вкладки и добавляется к административным запросам. Страница отображает список опросов, идентификаторы вариантов ответа, позволяет создать опрос в модальном окне и открыть агрегированную статистику без перехода на другую страницу. В статистике также показаны идентификаторы вариантов. Статус считается активным до наступления `ends_at`, после чего отображается как завершённый.

Корневой путь `/` содержит справку со ссылкой в административную часть и форматом ссылки для голосования `/poll/<uuid>/vote`. Страница голосования получает публичный опрос, отправляет выбор на API и показывает подтверждение только после ответа `201 Created`.

## Архитектура

Код разделён по зонам ответственности:

- `src/app/` — корневая композиция и определение маршрута без логики экранов;
- `src/pages/` — самостоятельные страницы: главная, голосование, вход и панель администратора, 404;
- `src/features/` — пользовательские сценарии: вход администратора, создание опроса и просмотр результатов;
- `src/entities/poll/` — типы доменного контракта опроса и публичные запросы голосования;
- `src/shared/` — повторно используемые HTTP-клиент, форматирование дат и UI-элементы.

Такое разделение не меняет HTTP-контракты или URL, но локализует состояние и представление сценария рядом с его API-вызовами.
